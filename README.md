# 電力需要と気温の関係分析

東京電力管内の時間別電力需要が、気温によってどこまで説明できるかを調べる。
pandas によるデータ処理を実データで身につけることが目的。

## データ

| データ | 出所 | 粒度 | 備考 |
|---|---|---|---|
| 電力需要実績 | 東京電力 でんき予報 | 1時間 | Shift_JIS、先頭2行はヘッダ外 |
| 気温・湿度・降水量 | Open-Meteo 過去気象API | 1時間 | 東京(35.69, 139.69)、APIキー不要 |

対象は 2023年・2024年。2023年は 8,760 行、2024年は閏年のため 8,784 行。

## セットアップ

```bash
uv sync                                      # 依存関係の復元
uv run python -m power_demand_analysis.fetch # data/raw/ に生データを取得
uv run jupyter lab                           # ノートブックで分析
```

生データは Git 管理外。`fetch.py` でいつでも再取得できる。

## 課題

分析は自分で書く。以下を順に進める。

### STEP 1 — 読み込みと結合

`src/power_demand_analysis/load.py` を新規作成し、2つの生データを1つの DataFrame にする。

- [ ] 電力データの `DATE` と `TIME` を結合して `datetime` 型の1列にする
- [ ] 気象データの `time` 列も `datetime` 型に変換する
- [ ] 日時をインデックスにして、2つを結合する
- [ ] 2023年と2024年を縦に連結して1つにまとめる
- [ ] 欠損値と重複がないか確認する

> ヒント: `pd.to_datetime`、`pd.merge`、`pd.concat`、`df.set_index`、`df.isna().sum()`、`df.index.duplicated()`
>
> **注意**: 電力の `TIME` は `0:00` 形式、気象は `2024-01-01T00:00` 形式。
> どちらも `pd.to_datetime` で扱えるが、`format` を明示したほうが速く、事故も減る。

### STEP 2 — 需要そのものを眺める

- [ ] 年間の需要推移を折れ線グラフにする
- [ ] 1日のうちどの時間帯に需要が高いか（時間帯別の平均）
- [ ] 曜日によって需要は変わるか
- [ ] 月別の平均需要はどんな形を描くか

> ヒント: `df.index.hour`、`df.index.dayofweek`、`df.groupby(...)`、`df.resample("D")`、`df.rolling(24)`

**問い**: 需要のピークは夏と冬のどちらが高いか。それはなぜだと考えられるか。

### STEP 3 — 気温との関係

- [ ] 気温を横軸、需要を縦軸にした散布図を描く
- [ ] 気温を 1℃ 刻みに区切り、区間ごとの平均需要を出す
- [ ] 平日と休日で分けて同じ図を描き、比較する
- [ ] 相関係数を計算する。そのうえで「相関係数だけでは不十分」な理由を考える

> ヒント: `pd.cut`、`df.corr()`、`ax.scatter(..., alpha=0.1)`

**問い**: 気温と需要の関係はなぜ V字（あるいは U字）になるのか。
この形に対して単純な線形回帰を当てはめると何が起きるか。

### STEP 4 — まとめ

- [ ] `reports/` に分析結果を Markdown でまとめる
- [ ] 図は 3〜5 枚に絞る。全部載せない
- [ ] 「何が分かったか」を最初に書く。手順は後ろ
